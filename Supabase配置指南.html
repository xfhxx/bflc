Supabase 配置指南

按以下步骤创建 Supabase 项目并配置后端，替换原来的腾讯云开发。

前提：Supabase 免费版提供 500MB 数据库、1GB 文件存储、50000 月活用户，完全够用。

第一步：注册 Supabase 账号

1打开 https://supabase.com
2点击右上角 Start your project
3用 GitHub 账号授权登录（推荐，最快捷）

第二步：创建新项目

1登录后点击 New Project
2填写项目名称：ai-workbench（随意）
3设置数据库密码：务必记住（记到备忘录里）
4选择区域：Northeast Asia (Tokyo) 或 Southeast Asia (Singapore)（离中国最近）
5点击 Create new project，等待 1-2 分钟初始化完成

第三步：创建数据库表

项目创建完成后，点击左侧 SQL Editor，点击 New query，粘贴以下 SQL 并点击 Run：

-- 1. 用户表
CREATE TABLE IF NOT EXISTS users (
  id BIGSERIAL PRIMARY KEY,
  uid TEXT UNIQUE NOT NULL,
  username TEXT UNIQUE NOT NULL,
  passhash TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. 工作台数据表
CREATE TABLE IF NOT EXISTS workbench_data (
  id BIGSERIAL PRIMARY KEY,
  uid TEXT NOT NULL,
  data JSONB,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. 创建索引
CREATE INDEX IF NOT EXISTS idx_users_username ON users(username);
CREATE INDEX IF NOT EXISTS idx_users_uid ON users(uid);
CREATE INDEX IF NOT EXISTS idx_workbench_uid ON workbench_data(uid);

-- 4. 开启行级安全（RLS）
ALTER TABLE users ENABLE ROW LEVEL SECURITY;
ALTER TABLE workbench_data ENABLE ROW LEVEL SECURITY;

-- 5. 设置 RLS 策略（允许 anon 角色读写）
CREATE POLICY "allow_all_users" ON users FOR ALL TO anon, authenticated USING (true) WITH CHECK (true);
CREATE POLICY "allow_all_workbench" ON workbench_data FOR ALL TO anon, authenticated USING (true) WITH CHECK (true);

-- 6. 创建存储桶（用于灵感图片上传）
INSERT INTO storage.buckets (id, name, public) VALUES ('inspirations', 'inspirations', true)
ON CONFLICT (id) DO NOTHING;

-- 7. 存储桶策略（允许匿名上传和读取）
CREATE POLICY "allow_storage_all" ON storage.objects FOR ALL TO anon, authenticated USING (bucket_id = 'inspirations') WITH CHECK (bucket_id = 'inspirations');

第四步：获取 Project URL 和 API Key

1点击左侧 Project Settings（齿轮图标）
2点击 API
3找到以下两项，复制下来：
  • Project URL — 形如 https://xxxxx.supabase.co
  • anon public key — 一长串 eyJ... 开头的字符串
注意：只需要 anon key，不要用 service_role key（那个有管理员权限，不能放前端）。

第五步：填入代码

打开 index.html，找到第 849 行附近的配置：

const SB_CONFIG = {
  url: '',            ← 把 Project URL 粘贴到这里
  anonKey: ''         ← 把 anon key 粘贴到这里
};

填完后类似这样：

const SB_CONFIG = {
  url: 'https://abcdefgh.supabase.co',
  anonKey: 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...'
};

第六步：测试

1用浏览器打开 index.html
2应该看到登录/注册界面（不再是"本地模式"）
3注册一个账号，然后登录
4在手机上打开同一个页面，用同一账号登录，数据应该同步
如果显示"本地模式"：说明 url 或 anonKey 没填对，检查一下引号和拼写。

常见问题

Q: Supabase 免费版有什么限制？

500MB 数据库、1GB 文件存储、50000 月活用户。对于个人工作台完全够用，不需要付费。

Q: 数据安全吗？

使用了 RLS（行级安全）策略，anon key 只能读写允许的表。密码用 hash 存储（非明文），但不是加密安全的——如果需要更高安全性可以后续升级为 Supabase Auth。

Q: 可以从腾讯云开发迁移数据吗？

之前的数据存在腾讯云开发的数据库里。如果你有重要数据，可以手动导出后再导入 Supabase。如果是新开始使用，直接注册新账号即可。

Q: 手机访问需要配置什么？

Supabase 不需要配置安全域名，默认允许所有来源访问。直接部署到 GitHub Pages 或任何静态托管即可。
